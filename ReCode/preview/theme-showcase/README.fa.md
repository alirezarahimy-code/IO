# پیش‌نمایش چهار طرح رابط کاربری

این یک نمونهٔ مستقل و ایستا برای مقایسهٔ ظاهر است، نه پنل عملیاتی و نه اتصال به پایگاه داده. همهٔ اشخاص، آمار و اطلاعات ساختگی‌اند. نوار بالایی برای انتخاب چهار طراحی کار می‌کند؛ بقیهٔ کنترل‌ها صرفاً پیام نمایشی نشان می‌دهند.

- مدرن سازمانی: منوی کناری روشن و کارت‌های آبی.
- طبیعت آرام: ناوبری افقی، پس‌زمینهٔ سبز و چیدمان متفاوت.
- گرم و مینیمال: منوی قهوه‌ای، فرم‌های زاویه‌دار و چینش تحریری متفاوت.
- مرکز فرمان: محیط تیره و منوی باریک آیکنی.

طراحی‌ها با یک صفحه و فایل CSS/JavaScript مرکزی نمونه نمایش داده می‌شوند. اینها هنوز به سیستم تم پنل واقعی متصل نشده‌اند و تأیید قابلیت‌ها یا انتخاب طرح نهایی محسوب نمی‌شوند. برای مشاهدهٔ محلی، از این پوشه `python3 -m http.server 4173` را اجرا کنید. قلم Vazirmatn از `@fontsource/vazirmatn` نسخهٔ 5.3.0 با مجوز SIL OFL در `assets/OFL.txt` قرار دارد.
