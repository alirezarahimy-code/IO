صف تست ارتباط دستگاه

این نسخه فقط TCP handshake به IP و پورت مجازشده در تنظیم worker را بررسی می‌کند؛ tcp-reachable به معنی احراز هویت، پشتیبانی مدل، دریافت اطلاعات یا اتصال SDK نیست. S05 تا S12 و آزمون واقعی بخش سوم هنوز تکمیل نشده‌اند. در نبود worker مستقل، درخواست pending می‌ماند؛ موفقیت فرضی نمایش داده نمی‌شود.

ثبت تست

UUID و نسخه را از موجودی دستگاه بردارید. برای هر دستگاه فقط یک تست ناتمام؛ timeout از ۱ تا ۶۰ ثانیه، از شروع worker محاسبه می‌شود، نه زمان ماندن در صف. حق test به‌تنهایی حق خواندن موجودی یا نتایج نیست.

تاریخچهٔ واقعی دیتابیس

لغو فقط پیش از claim و با نسخهٔ تازه ممکن است؛ صف running قابل لغو تضمینی نیست. پس از قطعی worker نتیجه interrupted می‌شود؛ retry خودکار نداریم. فیلتر دستگاه محدودهٔ امنیتی نیست؛ مجوزها سراسری‌اند.
