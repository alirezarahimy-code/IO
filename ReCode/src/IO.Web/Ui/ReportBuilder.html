چیدمان گزارش تشخیصی

انتخاب ستون‌های گزارش آخرین اجرای روزانه برای یک کارمند؛ بدون ذخیرهٔ طرح.

پارامترهای گزارش

نیازمند مجوز سراسری بررسی دوره است. بازهٔ میلادی یک تا ۶۲ روز و پایان انحصاری است.

ستون‌ها

انتخاب ستون فقط چیدمان پیش‌نمایش را تغییر می‌دهد؛ دادهٔ جدید محاسبه نمی‌شود.

ستون‌های قابل نمایش

پیش‌نمایش

حداقل یک ستون انتخاب کنید.

این ابزار فقط ستون‌های گزارش تشخیصی موجود را نمایش می‌دهد؛ ذخیرهٔ قالب، طراحی دلخواه، خروجی فایل، گزارش رسمی و اضافه‌کار پیاده‌سازی نشده‌اند. تازگی و تأیید کارکرد نامعلوم است.
