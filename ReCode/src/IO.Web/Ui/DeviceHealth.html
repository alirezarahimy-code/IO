سلامت صف و سرویس دستگاه

پنل · دستگاه‌ها

این صفحه مشاهده‌های ذخیره‌شدهٔ SQL را نشان می‌دهد، نه تست اتصال جدید. heartbeat تازه فقط گزارش همان process است؛ دستگاه آنلاین، SDK نصب‌شده یا اجرای موفق فرمان را ثابت نمی‌کند. نبود گزارش «گزارش نشده» است، نه قطع قطعی دستگاه.

آخرین خواندن موفق تردد با ورود آن به هسته تفاوت دارد. تعداد unknown تاریخچه است؛ لزوماً کار حل‌نشده نیست. جزئیات شخصی، نتیجهٔ تنظیمات و رمز در این صفحه وجود ندارد. عملیات تازه، retry، لغو یا نوشتن از این صفحه انجام نمی‌شود.

دستگاه‌ها و صف‌های واقعی

    instanceهای سرویس

    تازه: حداکثر ۹۰ ثانیه از ساعت سرور. قدیمی: گزارش تازه نداریم؛ نه اثبات خاموش‌بودن سرویس. stopped فقط توقفی است که خود instance توانسته در SQL ثبت کند. هر restart شناسهٔ جدا دارد؛ چند instance یک سرویس جدا نمایش داده می‌شوند.
