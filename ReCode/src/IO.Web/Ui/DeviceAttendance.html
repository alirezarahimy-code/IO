استخراج بازه‌ای تردد SDK و قرنطینه

پنل · نگاشت‌ها با مجوز مستقل

فقط SSR و تقویم Gregorian تأییدشدهٔ مدل؛ بدون clear/delete یا توقف دستگاه. SDK مشاهده‌شده همهٔ log را می‌خواند؛ همهٔ tupleها قبل از اعمال بازه محفوظ‌اند. شروع بازه شامل و پایان آن غیرشامل است. دریافت SDK به معنی ورود خودکار به محاسبات نیست.

شناسهٔ رخداد بومی در قرارداد مشاهده نشده؛ ادغام تکرار بر پایهٔ tuple و رتبهٔ تکرار همان tuple است، نه اثبات هویت فیزیکی رخداد. پس از پاک‌سازی/جایگزینی log یا رخداد کاملاً یکسان، هم‌ارزی فیزیکی تضمین نمی‌شود. آزمون دستگاه واقعی همچنان لازم است.
