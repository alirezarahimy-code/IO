# صورت‌جلسهٔ فنی فاز ۳

**تاریخ:** ۲۰۲۶-۱۱-۰۸

**نتیجه:** بنیاد اسکیما و migration اولیه با دادهٔ ساختگی روی SQL Server واقعی در محیط موقت ساخته و آزموده شد. شرط فنی ایجاد/rollback/بازسازی و قیود پایه برای این بنیاد برقرار است؛ خروج طراحی کسب‌وکار و آمادگی تولید **مشروط** به تصمیم‌ها و کارهای باز زیر است. این صورت‌جلسه تأیید فاز ۴ یا شروع آن نیست.

| مدل مفهومی کل دامنه | [سند اسکیما و عملیات](Schema-and-Operations.fa.md) محدودهٔ اجراشده و طرح مفهومی حوزه‌های آینده را تفکیک می‌کند؛ تصمیم‌های D09–D10 بازند. |
| اسکیما و migration نسخه‌دار | ۱۴ جدول پایه، روابط و قیود در `IoDbContext` و migration `20261108225421_InitialFoundation`؛ محدودیت‌ها و موارد پیاده‌نشده در سند ثبت شده‌اند. |

## موارد باز و انتقال به فازهای بعد

- **D09/D10:** جزئیات مجوز، نقش، جانشینی و مدل سازمان/استخدام باید پیش از نهایی‌سازی و اجرای قابلیت مربوطه تعیین شوند؛ فرض یک شرکت برای واحد و کارمند و انتساب درون همان شرکت قابل بازنگری با migration کنترل‌شده است.
- نبود اجرای مجوز، حسابرسی، جلوگیری از چرخهٔ چندواحدی یا هم‌پوشانی هم‌زمان انتساب، سیاست‌های retention و دسترسی دیتابیس و تست بازیابی backup، محدودیت‌های واقعی هستند، نه قابلیت‌های تحویل‌شده.
- تنها بنیاد SQL ایجاد شده است؛ تقویم، شیفت، دستگاه، درخواست، قواعد/محاسبه، دوره، گزارش، حقوق، گردش‌کار و کنترل فیزیکی در این migration وجود ندارند. نام‌ها در طرح مفهومی قرارداد نهایی نیستند.
- تحلیل اتمی ۱٬۲۲۲ خط مانیفست و بررسی رفتارهای قدیمی که در خروج مشروط فاز ۱ ثبت شده‌اند باز می‌مانند. پشتیبانی ZKTeco عملی نشده و Virdi از UNIS همچنان مشروط به امکان‌سنجی است.
- آزمون محلی SQL، استقرار، دیتابیس دائمی، migration داده و تست سیستم واقعی انجام نشده‌اند. **هیچ نتیجه‌ای دربارهٔ تولید یا انطباق کامل محصول از این تست استنتاج نمی‌شود.**
