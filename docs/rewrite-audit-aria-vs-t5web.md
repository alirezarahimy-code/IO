# ممیزی مقایسه‌ای: «آریا» و «T5Web» در برابر برنامه‌های منبع

**دامنه:** بازنویسی `TWF 4.28` (سامانه آریا) و بازنویسی `T5Web [3.5.7]`
**تاریخ:** ۱۴۰۴/۰۸/۰۳ · **مبنا:** فایل‌های همین مخزن، خوانده‌شده به‌صورت ماشینی
**شاخه:** `arena/a4df3135-io`

> **هشدار روش‌شناختی (مهم):** هیچ‌کدام از دو بازنویسی در این محیط کامپایل یا اجرا نشده‌اند
> (نه `csc`/`msbuild`، نه SQL Server، نه مرورگر). هر عدد این سند از **خواندن متن فایل‌ها**
> می‌آید، نه از اجرا. هرجا «سبز» می‌نویسم یعنی «گیت متنی سبز است»، نه «برنامه کار می‌کند».

مدل داده، گیت، آزمون و Runbook دارد.

## ۴. «چقدر هم‌خوان است؟» با تعریف شفاف هر عدد

import os, re

pat = re.compile(r'\n\s*public\s+(?:static\s+|virtual\s+|override\s+|async\s+)*([\w<>\[\], .]+?)\s+(\w+)\s*\(')
def methods(path):
    names = {n for _, n in pat.findall(open(path, encoding="utf-8", errors="replace").read())}
    return {n for n in names if not n.startswith(("get_", "set_"))}
total = present = 0
for name in sorted(os.listdir(src)):
    if not name.endswith(".cs"):
        continue
    left = methods(os.path.join(src, name))
    right = methods(os.path.join(new, name)) if os.path.exists(os.path.join(new, name)) else set()
    total += len(left)
    present += len(left & right)
print("source methods", total, "| same-name present", present)
