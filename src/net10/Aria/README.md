# آریا — برش AR-Core-01 (فقط هستهٔ قابل‌حمل، نه وب‌محصول)

`Core/Aria.Core.csproj` به‌صراحت `net10.0` را هدف می‌گیرد و ۱۵ فایل Domain، سه سرویس Application (ماندهٔ مرخصی، دسترسی سازمانی، مدل نشست) و یک اجرای مجوزدهیِ بدون قفل را **فقط از بازنویسی همین محصول** در `src/TWF/` با پیوند فقط‌خواندنی کامپایل می‌کند. این برش مستقل از آریا ادمین است و هنوز میزبان ASP.NET Core، کنترلر، Razor یا دسترسی واقعی به دیتابیس ندارد. C# فایل‌های پیوندشده 7.3 و `Nullable=disable` است؛ برای این اسمبلی x86 تنظیم نشده، چون هیچ DLL بومی یا وابستگی موتور اجرایی در آن بارگذاری نمی‌شود.

`TWF.Domain.Interfaces.IT5BackendAdapter` مرز صریحِ سازمان/تردد/موتور محاسباتی ویندوزی است، **نه** یک اجرای معتبر آن. DLLهای ۳۲بیتیِ موتورِ مرجع `TWF 4.28`، SQL و سازگارکنندهٔ خارجی عمداً در فرایند جدید وارد نشده‌اند؛ استفادهٔ عملیاتی بدون سازگارکنندهٔ جداگانه، آزمون Windows/x86 و خروجی طلایی نسخهٔ اصلی ممنوع است. سورس‌های پیوندی باید قبل از انتشار مستقل، با نسخهٔ مالکیتی بازبینی‌شده جایگزین شوند. نه قفل نرم‌افزاری/سخت‌افزاری تازه‌ای اضافه شده، نه شمارهٔ نسخهٔ تازه‌ای برای محصول اعلام شده است.

`Tests/Aria.Core.Tests.csproj` یک اجراکنندهٔ مستقل بدون NuGet و با ورودی ثابت `Tests/golden.json` دارد: ۱۰ آزمون مصنوعی برای تقویم شمسی و مرز سال/کبیسه، زمان فارسی، DTO سلامت دو کاتالوگ، قرارداد فعلیِ مجوزدهی بدون قفل، مدت نشست (فقط مدل، **نه رمزنگاری/کوکی وب**)، هویت مستقل هر فراخوانی، مقادیر شناسهٔ گردش کار و نبود پیوند/اجرای موتور. انتظارها از بخش‌های مشخص `src/TWF/TWF.Tests/Program.cs` و بازنویسی کنونی آمده‌اند؛ از باینری‌های `TWF 4.28` استخراج نشده‌اند. **هیچ** دسترسی به دادهٔ واقعی، رمز، کلید، دستگاه، دیتابیس یا اتصال تولیدی وجود ندارد. موفقیت ساخت/تست هسته برابری با نسخهٔ اصلی یا وب/IIS را ثابت نمی‌کند.

مبنای Framework همین بازنویسی طبق شواهد `src/net10/TEST_LOG.md` هنوز ساخته/اجرا نشده است: فایل‌های آزمون در میزبان واقعی Windows Framework کامپایل نمی‌شوند و هر ۴۷ ثبت آزمون آن تا این مرحله اجرا نشده‌اند. مقایسهٔ اصلی این محصول تنها با **`TWF 4.28`** انجام می‌شود؛ سایر محصولات معیار سنجش آن نیستند. وضعیت CI این برش پس از اجرای مستقل روی Ubuntu/Windows در همین سند و دفتر ثبت می‌شود؛ تا آن زمان هیچ نتیجهٔ اجرایی ادعا نمی‌شود.
