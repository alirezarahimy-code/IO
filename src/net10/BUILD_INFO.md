## TWF raw solution versus diagnostic source build

Windows [CI 40395889978](https://github.com/alirezarahimy-code/IO/actions/runs/40395889978) ran raw `TWF.sln` in Release using a pinned assembly search path: **FAIL** (CS0234/CS0246). TWF.Web.csproj lacks at least `System.Data`, `Dapper`, `System.Web.Http`, `System.Web.Optimization`; its engine HintPaths are too shallow by one `..`. The raw solution must not be described as compiling. Architecture warnings (MSB3270, x86 engines vs AnyCPU project) are real; they are not equivalent to compiler errors.

`src/net10/tools/test-twf-shadow.ps1` is an *additional* experiment: copy `src/TWF/` to Windows runner temp, explicitly add missing Framework and pinned non-engine reference metadata (and the original TWF CaptchaMvc library), include the existing but unlisted adapter source, then compile the copied solution and execute all 47 tests from an output under the actual source root. It never edits the tracked baseline. The *first* shadow used identical C# source bytes but modified project metadata and also failed. The subsequent optional `-DiagnosticPatch` **additionally changes one source line in the temporary copy** (`Init.Start` -> `TD5.Init.Start`). Even if that diagnostic passes, it proves only a patched-source test experiment, **not** a build of the original rewrite, original-Web parity, or a Core web app. Record its actual result before using it as evidence.

The first shadow build ([CI 40396358663](https://github.com/alirezarahimy-code/IO/actions/runs/40396358663)) still failed before tests: the Web project is missing `System.Xml` for `System.Xml.Serialization`. In the next shadow iteration the **test executable only** is marked x86 because it directly loads the `32BITREQUIRED` engine model; the web and portable domains are not assigned x86 by default. No part of this output establishes Razor compilation.

Second identical-source shadow [CI 40396626924](https://github.com/alirezarahimy-code/IO/actions/runs/40396626924) reached three remaining compiler blockers: missing `Microsoft.CSharp` binder, missing `System.Web.Http.WebHost`, and a genuine C# source error (`TWF.Web/MyTime3/MvcApplication.cs:31`, unqualified `Init.Start` shadows `TD5.Init`).
