# سامانه آریا (ARIA) — بازنویسی کامل TWF 4.28

**نام ثبت‌شده محصول:** سامانه حضور و غیاب و کارتابل آریا
**کد محصول:** `ARIA` · **نسخه:** `Aria v5.0`
**مبنا:** بازنویسی خط‌به‌خط `TWF 4.28` (`MyTime3.dll` + `TD5.dll` + تمامی `Views`)

---

## ۱. اصول حاکم بر بازنویسی

| اصل | توضیح |
| :--- | :--- |
| **همان زبان و پلتفرم** | C# / ASP.NET MVC روی .NET Framework — بدون تغییر پشته فناوری |
| **Zero-Lock** | قفل سخت‌افزاری `TINYLib` و هر وابستگی به لایسنس/دانگل به‌طور کامل حذف شده است |
| **۱۰۰٪ آفلاین** | بدون CDN، بدون Google Maps، بدون فونت/آیکون/اسکریپت آنلاین و بدون هیچ فراخوانی ابری |
| **معماری لایه‌ای** | `Domain` → `Infrastructure` → `Application` → `Web` + لایه دسترسی داده `TD5` (Dapper) |
| **وابستگی کامل به T5** | چارت سازمانی، سمت‌ها، گردش کار، سطوح دسترسی و سهمیه‌ها از `T5V3.9.2` و `T5Web` خوانده می‌شود |
| **ضدّ‌سلایق پیش‌فرض هوش مصنوعی** | رابط صنعتی Slate-Navy با شبکه ساختاریافته Swiss، بدون گرادیان تزئینی و بدون کارت‌های گرد تزئینی |

## ۴. پیش‌نمایش آفلاین

```bash
cd src/TWF && python3 -m http.server 8080 --bind 0.0.0.0
```

سپس:

- صفحه ورود: `http://<host>:8080/preview/index.html`
- داشبورد عملیاتی: `http://<host>:8080/preview/app.html`

پیش‌نمایش، دقیقاً از همان `twf-industrial-ui.css` و `twf-core.js` محصول استفاده می‌کند و شامل این صفحات است:
داشبورد، ثبت درخواست، کارتابل تایید، درخواست‌های من (زنجیره تایید و جانشین)، وضعیت پرسنل، مرخصی‌های امروز انتظامات،
گزارش موقعیت مکانی (بوم برداری آفلاین)، محدوده‌های مجاز (ترسیم چندضلعی)، گزارش‌ساز و تنظیمات.

## ۵. استقرار روی IIS (ویندوز سرور آفلاین)

1. پوشه `TWF.Web` را به‌عنوان Application در IIS تعریف کنید (`ASP.NET v4.0`، Pipeline: Integrated).
2. `bin/` را با خروجی کامپایل (`MyTime3.dll`, `TD5.dll`, `TWF.Domain.dll`, `TWF.Infrastructure.dll`, `TWF.Application.dll`) پر کنید.
3. رشته اتصال پایگاه‌داده T5 و Personnel را در `Web.config` تنظیم کنید.
4. کلید رمزنگاری نشست (`EncryptionKey`) را در `Web.config` مقدار‌دهی کنید.
5. هیچ مرحله فعال‌سازی لایسنس یا اتصال به اینترنت لازم نیست.

> نکته: `appSettings` شامل `LicenseMode=Zero-Lock` و `HardwareLockEnabled=false` است تا حذف قفل در سطح پیکربندی نیز صریح و قابل ممیزی باشد.
